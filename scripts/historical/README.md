# Historical preview launchers

E5 is a standalone saved synthetic experiment, retained at `e5-preview`.
Run it from this repository with `scripts/historical/e5-preview start`.
It has no acquisition authority and still needs its original ignored evidence.
Its module and exclusive assets are under `app/dashboard/historical/`;
current saved viewers use shared `saved_preview.py` and `static/saved-state.js`.
Applied migrations, recorded state and historical delivery manifests were not moved.
