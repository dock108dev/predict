## Extraction scope and commands

Run in Predict, no dependency installation:

```sh
PYTHONPATH=. .venv/bin/python examples/e1/paired_reference.py
node examples/e1/status_banner.mjs
```

The SDA probe supplies an explicitly synthetic object shaped to demonstrate traversal, keeps `book.key`, aligns an out-of-order pair, preserves long Decimal text and leaves a missing side null. It is not provider selection, a provider adapter, a complete timestamp/rules parser, or evidence of permitted data use. Its name/order inputs are already explicit; it does not duplicate canonical matching.

The Scroll Down probe exercises degradation → dismissal → recovery → degradation, preserves the source row's delayed state after dismissal, and carries explicit mode. It is a state-contract example, not a new E5 screen or a browser visual acceptance claim. Neither example imports, executes or writes into an archived source repository.

**Decision:** use only these two bounded adaptation patterns where E2/E5 needs them. Preserve Predict's normalization, matching, exact-money, fee/settlement, async collector, storage and vanilla dashboard foundation. Do not force direct code reuse or a framework migration to satisfy the audit.
