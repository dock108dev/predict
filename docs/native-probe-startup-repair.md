# Public native probe startup and subscription boundaries

The September 30 native-only attempt passed its exact authorization checks but failed before dispatch because `TransportSession.start` constructed a credentialed prediction stream producer. The public metadata probe correctly suppressed credential loading, making the constructor fail. Its attempt is consumed, no provider request occurred, and no journal was created. Original failure and metadata remain unchanged.

The public probe now leaves the base stream-producer map empty. `ContinuousSession` installs its existing REST discovery owners, preserving endpoint validation, pacing, request/body/parse accounting, source isolation and global resource stops. Normal real stream sessions still require their dedicated credentials. No general credential bypass was introduced.

Discovery already published an empty subscription selection, but `Venue.reconcile` recomputed eligibility from catalog markets. The probe now explicitly clears that recomputed selection at the subscription boundary as well. A valid market remains inspectable metadata and cannot cause a subscription in discovery-only mode.

Start failures before a task exists now close resources owned by that Start, close any journal, mark failed cleanup state and write a supplemental `startup-failure.json`. That file is a diagnostic, not a primary observation journal or replay success. Refusing a later Start for a consumed attempt cannot close an old resource again or rewrite its startup diagnostic. Real-mode failures no longer carry the misleading product-fixture error label.

Verification uses the ordinary Start/Stop and saved routes with mode=real, but replaces HTTP transport in memory with existing captured NFL bytes and clearly labeled empty control responses. External sockets, credential loading, `.env` reads and stream producer construction are forbidden by test guards. The 90-second test must remain free of WebSocket/aggregate traffic throughout reconciliation, then close cleanly and match exact fresh-process saved projection. These tests establish local branch behavior, not fresh listings or source qualification.

No new provider record was captured by the consumed attempt. US NCAAB's league identifier, non-NFL selector results, unknown kickoff/participant/period facts, actual native books and cross-source qualification remain external evidence gaps. No binding is inferred from the startup failure.
