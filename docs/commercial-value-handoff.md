## Deliberate calculation and resource limits

The ordinary equal-leg product engine supports whole-contract conditional returns. Fractional depth and raw acquisition arithmetic are retained exactly; fractional execution/fee applicability is withheld where native increments or the retail fee path do not support it. The US fee engine rejects unsupported fractional fills rather than silently rounding them. Verified native minimum/increment and partial-fill applicability are required before extending the return domain. No such new native evidence was supplied.

The existing finite-depth solver requires native sizing and fill-rule evidence that these product journals do not establish. This package therefore evaluates explicit sizes through the existing product path, discloses incomplete search, and makes no global optimum or fill guarantee. Provisional entry ranges remain separate from the existing explicitly hypothetical fee scenarios. Saved original scenario results are not rewritten as new qualified economics.

Watch storage is capped at 16 definitions. Signal state is capped at 1,024 candidate/watch identities, 2,048 transition events, and 64 sampled changes/spans per candidate; omissions are counted. History limits the total watch/cutoff evaluation budget to 4,096, reads the full verified journal, and explicitly reports skipped analysis cutoffs. One history reconstruction runs at a time outside the request event loop. The shared calculation cache is scoped to one snapshot and never carries facts across cutoffs. Older/truncated detail is never presented as exhaustive coverage.

Live in-app signals sample the admitted projection when the dashboard refreshes; a crossing entirely between those refreshes may appear only in journal reconstruction. No background collection, alerts, scheduler, email or push service was added. Raw-gap watches use the existing Kalshi/US same-outcome mapping; return watches use the shared venue/sport paths. Missing Novig/ProphetX facts remain unavailable rather than becoming invented raw comparisons. The full four-venue, six-sport beta scope is unchanged.
