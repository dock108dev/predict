**Start fresh runtime · expires reviews** is a whole-service recovery, not a paid refresh. Keep a board connected to attend. If another process acquires ownership, no overlapping worker starts.

Normal scheduler gates still apply at dispatch; a fresh service cannot bypass the persisted slot. Unknown/corrupt/contradictory accounting or reset/clock facts block recovery with a code and practical explanation.
