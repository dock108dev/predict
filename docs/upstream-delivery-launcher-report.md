- [Executable manifest](../app/collection/delivery_manifest.py): validates externally supplied exact configuration at serving, Start and worker entry. - Kalshi-only credential loading occurs inside the armed worker, after lock/marker creation and worker verification. It uses only service `prediction-arb.kalshi.production`, account `market-data`; it never invokes the two-venue loader. Errors crossing the process boundary are fixed sanitized events. Native request values, selected identity, GET signing, exact hosts, redirect/proxy suppression, disconnected-request accounting, and a single WS attempt are guarded. Offline execution injects synthetic keys and loopback destinations only after exercising the native validation path; no production override flags exist.
- [Independent watchdog](../app/collection/delivery_watchdog.py): explicit Start clocks precede worker initialization; the worker cannot load credentials before the watchdog arms. Scheduled +240 Stop uses the owner's same handler. The watchdog enforces +300 intake and closure+300 finalization limits without the collector/control event loop, retains TERM → one-second grace → KILL escalation, and detects supervisor/heartbeat loss. It also stops failed initialization at +60. An intake-closed message alone does not relax the +300 cutoff while transport cleanup is blocked. Worker/watchdog CPU caps respect tighter inherited limits rather than raising them.
- Accounting reserves the existing 8 MiB helper allowance inside the 120 MiB output/160 MiB cumulative-write caps. Collector guards and finalization reserve that allowance; append-only launcher files, external marker, failed-Start report and fixed 64 KiB outer receipt are counted. The collector's existing fixed 16 KiB receipt and its measurement boundary are unchanged. Interrupted collector writes and killed-worker lifetime memory remain unknown. The [read-only auditor](../tests/delivery_launcher_audit.py) reconciles complete attempts and has separate full-duration qualification gates; a short successful mock cannot pass those gates.
