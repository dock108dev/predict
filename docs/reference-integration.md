## Local preparation and import

`python -m app.reference.product capture-annotations.json prepared-references.json` reads only a bounded local annotation file and creates a new output without overwriting an existing file. Each entry names `parser` (`published_value`, `pinnacle`, or `kenpom_fanmatch`), `receipt` (`body`, `provider`, credential-free `url`, `received_at`, `mode`, optional status/headers), an explicit `binding` with the complete canonical market identity/participant/source event, and parser `options`. Published text also requires exact start/end offsets, original kind/convention and event/outcome/date literals. This is engineer-prepared mapping evidence, not owner-entered probability guessing.

Use **Import retained references** on an explicitly started ordinary product session to load the prepared file (maximum 1 MiB/16 records). The API reparses every original receipt before any record is admitted. Invalid batches fail validation before import; disk/queue failures remain subject to the collector's existing failure handling. Stop prevents later admission. No saved package is edited in place, no provider is contacted, and a synthetic record cannot enter a real-mode session.
