# Using the SC05 manual ticket

SC05 is an isolated implementation. The ordinary installation remains its prior version until SC07 qualifies and installs the combined successor. The preview uses authored positions and invented qualified routes, clearly labeled; it establishes no current opportunity, valid destination or owner acceptance.

After the qualified version is installed:

1. Choose supported venues and optional sport, market, edge or size filters. Both positions must use included venues. The scanner remains globally ranked; Find searches the displayed page. Amount is optional and does not change discovery rows.
2. Select an opportunity. Read its category first: a conditional hedge can lose in exceptional outcomes, and EV is an expectation. The panel shows both exact native actions, quantities, prices, independent funding and requested/deployed/residual cash. Original input clocks and one-buffer reconciliation remain inspectable.
3. Change Amount and check it. The previous selected calculation stays intact; a proposed replacement shows separate allocations and changed fields. Use **Adopt updated allocations** only after reviewing it. Status reads do not renew old prices.
4. Allocation copying and exact-market links appear only when the current top-level ticket is actionable and destinations are qualified. Missing routes have an explicit explanation. **Copy market identity / search text** copies identification only. American odds are comparisons, never native order limits. Neither a ticket nor a copy reserves liquidity or submits an order.
5. If prices or supported depth change, action authority disappears while a replacement is checked. Expiry, Stop, connection failure and incompatible context also remove it. An expired slot or changed context can be explicitly rebound to the same position when supported. Close or Escape restores scanner focus; ordinary updates preserve the Amount draft and disclosures.
6. Sound starts off. Enable it deliberately, or mute it from the same control. Cues cover the selected server filters across the supplied universe, including rows beyond this page. Page movement, Find, filter changes, reload, reconnect and unknown continuity are silent. Earlier unseen opportunities remain unknown.

No login, order, account change or provider request is triggered by filtering, ticket inspection, sizing, adoption, copying or local sound. Current source/model/route qualification, full integrated performance, installation and SC08/Q04 owner review remain separate gates.
