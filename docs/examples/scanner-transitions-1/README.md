# Authored scanner transition examples

These explicit local scalar fixtures exercise the versioned [transition contract](../../scanner-transition-contract.md) and [schema](../../contracts/predict-scanner-transitions-1.schema.json). They are implementation evidence, not current source qualification or complete market history.

`baseline.json` is silent and censored. `improved.json` carries a supported same-episode economic improvement. `withdrawn.json` shows an observed category loss while the pair remains evaluated. `stopped.json` discards continuity and emits no arrival. Filters apply to the entire supplied universe; a row moving into or out of a ranked page does not create an event.
