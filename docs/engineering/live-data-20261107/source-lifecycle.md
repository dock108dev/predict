The implementation recognizes scheduled, live, suspended, final and unknown. An observed final or suspended event withdraws current price eligibility. Reconnection still requires native reimaging; saved metadata cannot restore book authority. Source-evidenced live/final/suspended occurrence metadata can remain for at most 24 hours after start, within the existing row/byte/disk caps. This is storage eligibility, not price freshness: live prices keep the existing 15-second ceiling. Old pregame evidence never extends itself beyond kickoff.

The existing aggregate cadence is 15 minutes. It therefore cannot supply continuous current in-game odds under a 15-second ceiling. This is a specific source/cadence limitation, not an excuse to relabel retained prices current. Live fee/reference calculations remain explicitly unavailable because the current reviewed models are pregame-scoped. No new settlement, period, line or occurrence equivalence is inferred.
