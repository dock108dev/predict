### Structural repair and its exact reuse boundary

`capture_structure.py` adds bounded, non-executable immutable catalog plans to
ordinary capture. It reuses event/group/outcome topology and exact native contract
rules only after proving the complete ordered structural records and governing
rule content unchanged. The binding also includes engine/policy, epoch, settings,
runtime/control identity and source states. The latest proof replaces the prior
proof for the same complete source-event neighborhood. No extra worker or SQL
writer was added; persistence remains under the existing publication advisory lock.

Every capture rebinds the newly captured source/event/contract identity, original
price, complete depth, source/confirmation clocks, receipt provenance, occurrence
witness and current binding. Reference acquisition/resolution, fee/model/settings
inputs, authority and the complete serializers/validators still run afresh. Price,
depth, reference probability and financial results are absent from stored plans.
Unknown structural fields invalidate reuse. A quote-derived material hash rebuilds
the exact native contract identity. Changed rule evidence, membership, epoch,
settings or controls causes a miss; Stop, reconnect/resync and removal still use
the existing authority/cancellation owners. A cache hit never renews freshness.

Bounds are 512 entries / 4 MiB compressed, 8 MiB decoded per entry, a 6 MiB atomic
JSON transfer and two-hour TTL. Corruption, expiry and overflow rebuild safely.
Level-six compression bought about 23% more neighborhood coverage inside the
same byte limit in the measured plan set. Private structural shells avoid copying
large quote trees merely to discard them; discovery proof construction likewise
copies only the shells it edits. Outputs remain detached from source records.
This removes repeated useful computation for every source/family with unchanged
structure; it does not move priority slots between markets or drop required depth.
