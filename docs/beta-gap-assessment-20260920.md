# Beta gaps

Predict is not ready for beta signoff. The [product definition](product-roadmap-review.md)
sets the required scope, and the [delivery plan](data-coverage-plan.md) records the
current handoff.

| Area | Implemented or retained | Still needed |
| --- | --- | --- |
| Prediction venues | Shared adapters, source health, original-input history and bounded Kalshi/Polymarket US observations | Current production qualification across Kalshi, Polymarket US, Novig and ProphetX; pending provider access and native field verification |
| Independent model | Dated reference imports, identity binding, conditional EV and exact replay | Actual usable forecasts, model independence and supported distributions for the selected markets |
| Delayed Pinnacle | One historical NFL sample with 16 side references | Broader observed coverage, delay evidence and compatible prediction/settlement inputs for EV |
| Sports and markets | Six-sport winner/line calculations, selected partial periods, college identities and championship futures, verified offline | Native listings, aliases, rule applicability, fees, depth and corresponding forecasts |
| Results and settlement | Separate sporting results and venue decisions, corrections and saved cutoffs | Actual source records and supported exceptional payout terms |
| Product operation | Shared dashboard, filters, Details, Start/Stop, saved reopening and approximately 30 minutes of segmented offline validation | Useful joint operation with the required actual sources, then owner review |

The September 23 public investigation resolved the Polymarket US rule hierarchy.
Historical contract applicability, Kalshi amendment/fee priority and additional
mandatory-charge questions remain. The four retained net comparisons are still
unavailable. See the [public research handoff](public-research-handoff.md).

Novig and ProphetX replies are pending. KenPom and NHL analytics are deferred;
MoneyPuck is dropped. No replacement search or repeat acquisition is queued.
The model reference and delayed Pinnacle are separate requirements. Existing
saved-page research does not replace either one.

Unknown inputs remain explicit. Negative, zero and unavailable calculations are
valid when the original-input math is correct; a profitable result is not an
acceptance requirement. Offline tests establish implementation behavior, while
actual data qualification and owner acceptance remain separate.

Detailed source and market dependencies are in the [coverage matrix](coverage-matrix.md),
[reference contracts](reference-source-contracts.md) and [market data gaps](market-data-gaps.md).
