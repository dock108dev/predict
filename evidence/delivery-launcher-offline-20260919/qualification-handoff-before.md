A single disconnected GET therefore cannot silently become two server requests inside one counted call on the tested library version. The [retry review](../evidence/upstream-diagnostic-offline-20260919/http-retry-review.md), `Integration.test_http_disconnect_is_one_network_attempt`, `Native.test_no_reference_retry_429`, and quota/pacing tests cover this distinction. Neither timed run encountered the disconnect failure, so their observed ordinary request totals remain useful historical evidence. They do not qualify the final retry seam, authenticated signing/TLS path, or installed dependencies for future execution.
