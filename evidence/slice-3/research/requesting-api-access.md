# Requesting API Access

Request access to the ProphetX API by submitting the access form, contacting support, and reviewing the next steps for API onboarding.

Request access to the ProphetX API by submitting the access form and following up with support if needed.

## Request Trading API access

1. Submit a new access request: [New Access Request](https://prophethelp.zendesk.com/hc/en-us/requests/new)
2. Contact support if you need help with the request process: <hello@prophetexchange.com>
3. Visit the general support portal for additional help articles and request tracking: [ProphetX Support](https://prophethelp.zendesk.com/hc/en-us)

## What happens next

After you submit the form, the ProphetX team will review your request and grant API access if your application is approved.

If you need help during onboarding, contact the support team directly at <hello@prophetexchange.com>.
