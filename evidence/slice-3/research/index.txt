## API Reference
- [Authenticate session](https://docs.prophetx.co/reference/post_auth-login.md): Please access to our website, in Settings/Token to get/create a list of tokens to login with this endpoint
- [Refresh session](https://docs.prophetx.co/reference/post_auth-refresh.md): Please use this endpoint to refresh your "access_token" after login, access_token will expire after 10 minutes and can be refresh using "refresh_token" given by /auth/login endpoint
- [Cancel all orders](https://docs.prophetx.co/reference/post_v4-mm-cancel-all-orders.md): Cancel all orders

- [Cancel all unmatched orders related to a market](https://docs.prophetx.co/reference/post_v4-mm-cancel-orders-by-market.md): Cancel all unmatched orders related to a market
- [Get Order by Order ID](https://docs.prophetx.co/reference/get_v4-mm-get-order-id.md)
- [Order history](https://docs.prophetx.co/reference/get_v4-mm-get-order-history.md): Date range filter. At least one of the following date ranges is required: `from`/`to` for the order creation time, or `updated_at_from`/`updated_at_to` for the order update time. For each date range, either the `from` or `to` parameter can be provided, or both.
- [Get order matched detail](https://docs.prophetx.co/reference/get_v4-mm-get-order-matched-detail.md)
- [Get price ladder](https://docs.prophetx.co/reference/get_v4-mm-get-price-ladder.md): Provide a list of valid prices

- [Submit multiple orders](https://docs.prophetx.co/reference/post_v4-mm-submit-multiple-orders.md): ### Note for `failed_orders`  The `index` field of `failed_orders` is the index of the order in the request's order list  ```json {     "data": {         "succeed_orders": [],         "failed_orders": [             {                 "request": {                     "price": 100,                     "quantity": 1000,                     "strike_id": "c8151bb0106b4225132e1eed71214e8c",                     "external_id": "order-fbfd34c6-779a-11ed-a1eb-2242ac000000"                 },                 "error": "order_external_id_existed",                 "message": "given user id already has order with the same external id",                 "index": 0             },             {                 "request": {                     "price": 100,                     "quantity": 1000,                     "strike_id": "af92eecef365f00657df5da3f2d83d5c",                     "external_id": "order-fbfd34c6-779a-11ed-a1eb-2242ac000001"                 },                 "error": "order_external_id_existed",                 "message": "given user id already has order with the same external id",                 "index": 1             }         ]     } } ```
