Set up your data sources
  1. Choose sports and markets in .local/predict-current-config.json. The example in config/current.example.json starts with collection off.
  2. Follow docs/configuration.md in the project folder to add your read-only keys. Native keys go in the macOS login keychain. SportsGameOdds uses the private .env file.
  3. Turn on the collection you want. Run scripts/opportunity-board check-config, then scripts/opportunity-board start --role data. If it is already running, stop and restart the data role with the same configuration.

Use Spending to check your provider allowance and Overview to Stop or resume updates. Synthetic practice works without an account.
